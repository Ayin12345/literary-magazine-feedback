# Literary Magazine — Site Mockup

This is a rough draft of the website. No real styling, no real text — just the skeleton showing what pages exist and where content would go. Everything in brackets like `[Magazine Name]` is a placeholder.

---

## What's here

- **Home** — hero section with magazine name + tagline, 3 feature cards linking out to main sections
- **Submissions** — guidelines page, submission form area
- **About Us** — team/staff section
- **Achievements** — awards, recognition, etc.
- **Artworks** — gallery page
- **Previous Issues** — archive of past volumes
- **Deadlines** — submission deadlines
- **GoFan** — ticketing/events page

---

## What I need from you

**Design**
- Color scheme — what colors do you want? Right now it's plain black and white
- Fonts — any preferences, or keep it classic/editorial?
- Anything that should move — if a page or section feels like it's in the wrong place, say so

**Content**
- Actual text for each page (tagline, about blurb, submission guidelines, etc.)
- Any real images — logos, past cover art, team photos

**Home page specifically**
- Should the home screen have a cover image or piece of artwork to make it more visual/vibrant?
- Or keep it minimal and let the color scheme do the work?

**Features**
- Is a mailing list something you'd want on the site? (Newsletter signup, submission notifications, etc.) — worth knowing early since it affects what we'd need to set up
