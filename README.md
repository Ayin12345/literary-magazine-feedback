# Literary Magazine — Site Mockup

This is a rough draft of the website. I didn't add any styling or backend or anything specific, just the skeleton showing what pages exist and where content would go. Everything in brackets like `[Magazine Name]` is a placeholder.

---

## What's here

- Home — hero section with magazine name + tagline, 3 feature cards linking out to main sections
- Submissions — guidelines page, submission form area
- About Us — team/staff section
- Achievements — awards, recognition, etc.
- Artworks — gallery page
- Previous Volumes — archive of past volumes
- Deadlines — submission deadlines
- GoFan — to buy website

---
